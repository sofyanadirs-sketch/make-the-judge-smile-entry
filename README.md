One warm line about a small good thing today: the laundry lady sewed my shirt's third missing button back with red thread — the only colour she had — and charged nothing, so the button would stop winking at people. Running `main.py` prints that exact line to stdout and writes it, with no trailing newline, to `entry.txt`.

## Run it

```sh
python3 main.py
```
